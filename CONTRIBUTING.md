# Contributing

Report bugs with the calculator, inputs, expected result, actual result, browser
and language. Include a formula or technical source when changing calculations.
Keep product codes, material keys, units and thread standards stable unless a
technical change explicitly requires it. Preserve WordPress CSS isolation.

Open focused pull requests, update relevant documentation and run the documented
checks. Keep credentials, customer information and internal business documents
out of commits. Contributions are submitted under this repository's MIT license.
SmiCut reviews contributions before merging into the official version.
