How to use SmiProg

1
Define the thread

Select material, thread profile, thread size, thread length and safety distance.

2
Select the thread mill

Use a suggested SmiCut tool or enter custom tool dimensions in the tool selection.

3
Check output

Review cutting data, machining time and the Fanuc CNC program before machining.

Before machining

Check that the selected thread mill can machine the thread diameter, pitch and thread length. Confirm the program in simulation or single block before running production.

Machining Notes

Tool Compensation

Compensation of tooling is normally only needed for small adjustments. Large compensation values can cause problems. Use a value close to zero for cutter diameter compensation in the control system tool library.

Correct Thread Diameter

The pitch diameter is usually checked with a thread plug gauge or another accepted thread measuring method. If adjustment is needed, compensate in the machine control rather than changing standard thread data.

Custom and Special Tools

If your tool is not in the list, choose custom tool dimensions in the tool selection and enter cutter diameter, cutting length and number of flutes. Verify the generated program carefully when using custom tooling.

ThreadBurr

To use the deburring feature of solid carbide thread mills from SmiCut, input the complete cutting length of the tool in the thread length box. That way the threading and deburring will be made in the same operation.

Read more in the article ThreadBurr Solid Carbide Thread Mills.

Thread Mills with One or Two Rows of Teeth

SmiProg compensates for standard SmiCut cutters with one or two rows of teeth. When using a non-standard cutter, check the cutting length and pitch relationship before machining.

Flank Infeed

SmiProg uses flank infeed when programming multiple radial passes. This helps reduce vibration and improves machining stability.

Read more in the article Vibration-Free Thread Milling.

Short Cutting Length

If the selected tool has a shorter cutting length than the requested thread length, SmiProg divides the operation into several axial passes when the tool type supports it.

Thread Mills with Inserts

Use custom tool dimensions in the tool selection to get cutting data for indexable thread mills. Enter the actual cutter diameter, cutting length and number of inserts or flutes, then verify the generated program before machining.

Tapered Threads

For tapered threads, the cutter diameter is related to the last full thread closest to the shank. Register the thread diameter at that position for correct CNC output.

Warning

The cutting data in SmiProg is recommended starting data. Many factors can require adjustments, including workpiece material, machine stability, fixturing, tool setup, coolant and chip evacuation.
